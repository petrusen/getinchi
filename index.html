📋 Click to view Instructions
  • 2D to SMILES: Draw your chemical structure on the board below, then click the purple button to generate its canonical SMILES, InChIKey, and InChI strings.
  • SMILES to 2D: Paste or type a valid SMILES string into the text container at the bottom, then click the orange button to automatically generate and render its 2D coordinates on the board.
🔒 Privacy Note: Molecular data and input strings provided by users are not transmitted, tracked, or stored on any server. This application is entirely static, served globally via GitHub Pages, and all computations run client-side in your web browser. If you want to know more, check out the README.md.
